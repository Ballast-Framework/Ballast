# AI security maturity scorecard

[Download the Excel scorecard](AI_Security_Maturity_Scorecard_AISMM_template.xlsx)

This optional aid supports discussion of the organization's AI security program using 12 categories and five maturity levels based on the [CSA AI Security Maturity Model (AISMM)](https://cloudsecurityalliance.org/artifacts/ai-security-maturity-model). It is a category-level self-rating tool, not a full AISMM assessment or an official CSA workbook.

Use program maturity to identify improvement priorities. Keep it separate from asset risk ratings, [Control Tiers](../tiering.md#control-tiers) and Ballast control coverage. See the [adoption guide](../adoption.md#assess-program-maturity-separately) and [AISMM alignment](../../mappings/crosswalk.md#csa-ai-security-maturity-model-aismm-alignment).

## Use the template

1. Open the workbook and use **Save As** to create a separate file for each assessment. It is a reusable `.xlsx` workbook, not an Excel `.xltx` template file.
2. Read the instructions and the maturity descriptions in **Questionnaire**. Enter one whole-number score from **1 to 5** for each of the 12 categories; all inputs start blank.
3. Rate practices already achieved across the assessment scope, supported by evidence. Do not score plans or isolated pilots as established practice. If a level is only partly achieved, choose the lower level.
4. Review **Dashboard** to identify priorities, then record owners and improvement actions alongside the assessment.

## Read the scores

- Unanswered categories remain blank and show **Not scored**.
- A domain average appears after all four categories in that domain have valid scores. The overall average appears after all 12 categories have valid scores and gives each category equal weight.
- Incomplete summary ratings show **Incomplete**. An invalid pasted value shows **Invalid score** and blocks the affected summaries until corrected.

Summary averages support discussion and tracking; they do not establish an official AISMM maturity rating or certification.
