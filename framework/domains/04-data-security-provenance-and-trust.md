# Domain 4: Data Security, Provenance & Trust

**Objective:** Keep data protections intact wherever AI copies or moves data, from prompts and retrieval to memory, outputs and model weights, and know where the content that grounds, remembers and trains AI came from and whether it can be trusted.

## Why it matters

AI copies data into places existing controls were not built for: prompts, retrieval indexes, embeddings, caches, memory, logs and model weights. Each copy can lose its source's labels, permissions and retention rules, and an embedded copilot grounds on everything a user can already open, so years of oversharing become one search away. Enforcement can fail silently: from January 2026 a code defect (CW1226324) let Microsoft 365 Copilot Chat summarize email labeled confidential despite DLP policy. Integrity matters as much. In GeminiJack (disclosed December 2025), a shared document retrieved during enterprise search became an exfiltration trigger, and a poisoned memory entry can steer every later session. Citations and groundedness show that an answer matches retrieved content, not that the content is trustworthy.

**Key risks addressed**

- [OWASP Top 10 for LLM Applications 2026](https://github.com/GenAI-Security-Project/GenAI-LLM-Top10/blob/main/2026/README.md): LLM02:2026 Sensitive Information Disclosure; LLM05:2026 Data and Model Poisoning; LLM09:2026 Vector and Embedding Weaknesses
- [OWASP Top 10 for Agentic Applications 2026](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/): ASI06 Memory & Context Poisoning
- [MITRE ATLAS](https://github.com/mitre-atlas/atlas-data/releases/tag/v2026.09) (release 2026.09): AML.T0057 LLM Data Leakage; AML.T0070 RAG Poisoning; AML.T0071 False RAG Entry Injection; AML.T0080.000 AI Agent Context Poisoning: Memory; AML.T0082 RAG Credential Harvesting

Control-level references to OWASP, [MITRE ATLAS](https://github.com/mitre-atlas/atlas-data/releases/tag/v2026.09), [NIST AI RMF](https://www.nist.gov/itl/ai-risk-management-framework) and [ISO/IEC 42001](https://www.iso.org/standard/42001): [Standards crosswalk](../../mappings/crosswalk.md#domain-4)

## Origin classes for retrieval sources

[BAL-4.9](../../controls/control-catalog.md#bal-4-9) designates each indexed source with a specific origin class. [BAL-4.12](../../controls/control-catalog.md#bal-4-12) displays this class within citations, and [BAL-6.2](../../controls/control-catalog.md#bal-6-2) incorporates the untrusted designation into the model's context. The class's determination is contingent upon **who can write** relating to the source, and not identifying the entity capable of accessing it.

| Origin class | What it covers | Treated as |
|---|---|---|
| Curated internal | Content written only by a named, approved writer set inside the organization and published through review (for example policies, product documentation, approved knowledge bases) | Trusted, while the writer population stays within the approved set |
| User-generated internal | Content that any employee or a broad internal group can write (for example wikis, team sites, tickets, chat, shared drives) | Untrusted when the writer population is broader than the approved writer set; otherwise trusted |
| External or inbound | Content authored or arriving from outside the organization (for example inbound email, web pages, externally shared documents, customer or supplier submissions, third-party feeds) | Always untrusted |

An asset that indexes any untrusted source carries the UNTRUSTED tag ([BAL-1.5](../../controls/control-catalog.md#bal-1-5)). "Trusted" does not mean safe from compromise. A curated source whose writer account is compromised is still a poisoning path. That is why sources must be traceable and removable ([BAL-4.9](../../controls/control-catalog.md#bal-4-9)) and, at [T2](../../guides/tiering.md#t2), restorable ([BAL-4.14](../../controls/control-catalog.md#bal-4-14)).

## Starting point for an embedded copilot

A vendor-operated copilot that grounds on users' content (tags RAG, UNTRUSTED, MEM) carries these Domain 4 controls at [T1](../../guides/tiering.md#t1): [BAL-4.1](../../controls/control-catalog.md#bal-4-1) (handling rules, tested), [BAL-4.8](../../controls/control-catalog.md#bal-4-8) (oversharing remediation before enablement), [BAL-4.10](../../controls/control-catalog.md#bal-4-10) (memory off unless governed), [BAL-4.4](../../controls/control-catalog.md#bal-4-4) (retention, including vendor-held memory), [BAL-4.6](../../controls/control-catalog.md#bal-4-6) and [BAL-4.11](../../controls/control-catalog.md#bal-4-11) (input and output protection at the points the organization controls), plus the program-level [BAL-4.5](../../controls/control-catalog.md#bal-4-5) coverage map. [BAL-4.2](../../controls/control-catalog.md#bal-4-2) is added if the copilot is rated High.

Provider-side prompt-cache isolation is evidenced under [BAL-8.3](../../controls/control-catalog.md#bal-8-3). | [BAL-4.9](../../controls/control-catalog.md#bal-4-9) | RAG source registration and trust labeling | Retrieval permissions ([BAL-4.7](../../controls/control-catalog.md#bal-4-7)) do not help when an attacker's content is legitimately readable. Origin classes are defined below. |
| [BAL-4.10](../../controls/control-catalog.md#bal-4-10) | Agent memory governance and integrity | Microsoft reported in February 2026 more than 50 prefilled-prompt 'Summarize with AI' links from 31 companies that planted memories favoring a source (AML.T0130, AML.T0131). Memory status is inventoried in [BAL-1.10](../../controls/control-catalog.md#bal-1-10). Detection of risky writes is [BAL-7.12](../../controls/control-catalog.md#bal-7-12), where implemented. |
| [BAL-4.11](../../controls/control-catalog.md#bal-4-11) | Output disclosure control | Recipient-aware release lets an HR partner receive an employee's record while an agent emailing outside the organization cannot include it. Credentials reach output through retrieval (AML.T0082), tool results and memory, so input checks ([BAL-4.6](../../controls/control-catalog.md#bal-4-6)) do not replace this one. Measured guardrail efficacy is [BAL-5.11](../../controls/control-catalog.md#bal-5-11), where implemented. |
| [BAL-4.12](../../controls/control-catalog.md#bal-4-12) | Retrieval-generated source attribution | Citations make an answer look authoritative, and crafted or poisoned content exploits that (AML.T0067.000).
