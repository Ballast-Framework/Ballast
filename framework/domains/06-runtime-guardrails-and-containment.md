# Domain 6: Runtime Guardrails & Containment

**Objective:** Constrain what models and agents can do at runtime through deterministic controls outside the model, so that a successful prompt injection or a misbehaving agent has a small, contained and observable effect.

## Why it matters

Prompt injection is the defining runtime threat to AI assistants and agents, and no model or detector stops it reliably, because instructions and data share one token stream. In EchoLeak (CVE-2025-32711, 2025), one crafted email could make Microsoft 365 Copilot leak data through an auto-fetched image after evading a production injection classifier. In ShareLeak (CVE-2026-21520, Copilot Studio, 2026), the request was reportedly flagged and the data left anyway. Agents with shells, ambient credentials, open egress or self-editable settings turn the same weakness into code execution and lateral movement. This domain assumes the model will sometimes be fooled and puts the boundary in deterministic controls the model cannot change: authority set outside the model, closed rendering and egress channels, isolated execution, hard limits and locked configuration. Detection is a tripwire.

**Key risks addressed**

- [OWASP Top 10 for LLM Applications 2026](https://github.com/GenAI-Security-Project/GenAI-LLM-Top10/blob/main/2026/README.md): LLM01:2026 Prompt Injection; LLM02:2026 Sensitive Information Disclosure; LLM10:2026 Improper Output Handling; LLM08:2026 Hidden Context Exposure; LLM06:2026 Unbounded Consumption; LLM07:2026 Misinformation
- [OWASP Top 10 for Agentic Applications 2026](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/): ASI01 Agent Goal Hijack; ASI02 Tool Misuse & Exploitation; ASI05 Unexpected Code Execution (RCE); ASI07 Insecure Inter-Agent Communication; ASI08 Cascading Failures
- [MITRE ATLAS](https://github.com/mitre-atlas/atlas-data/releases/tag/v2026.09) (release 2026.09): AML.T0051 LLM Prompt Injection; AML.T0077 LLM Response Rendering; AML.T0086 Exfiltration via AI Agent Tool Invocation; AML.T0081 Modify AI Agent Configuration; AML.T0105 Escape to Host; AML.T0132 Misconfigured or Publicly Exposed AI Services

Control-level references to OWASP, [MITRE ATLAS](https://github.com/mitre-atlas/atlas-data/releases/tag/v2026.09), [NIST AI RMF](https://www.nist.gov/itl/ai-risk-management-framework) and [ISO/IEC 42001](https://www.iso.org/standard/42001): [Standards crosswalk](../../mappings/crosswalk.md#domain-6)

## Why detection is not enough

Prompt injection detectors stop opportunistic payloads and produce useful telemetry, but they do not hold up against an adaptive attacker. *The Attacker Moves Second* (Nasr, Carlini, Tramèr et al., arXiv 2510.09023, 2025) bypassed 12 published defenses, most with attack success rates above 90%. The UK NCSC reached the same view in December 2025: unlike SQL injection, prompt injection may never be fully mitigated, so organizations should reduce what a fooled model can do through deterministic, non-LLM safeguards. Ballast therefore treats detection ([BAL-6.4](../../controls/control-catalog.md#bal-6-4)) as a tripwire that triggers a response, never as the control of record. The boundary sits in deterministic controls the model cannot alter:

- capability separation ([BAL-3.5](../../controls/control-catalog.md#bal-3-5))
- authority set outside the model ([BAL-6.1](../../controls/control-catalog.md#bal-6-1))
- closed rendering channels ([BAL-6.3](../../controls/control-catalog.md#bal-6-3))
- execution isolation ([BAL-6.13](../../controls/control-catalog.md#bal-6-13))
- default-deny egress ([BAL-6.14](../../controls/control-catalog.md#bal-6-14))
- human approval of high-risk actions ([BAL-3.6](../../controls/control-catalog.md#bal-3-6))

Where utility allows, design patterns that keep untrusted data out of an agent's control flow go further. These include the patterns catalogued by Beurer-Kellner et al. (arXiv 2506.08837, 2025), such as plan-then-execute and dual LLM, and the information-flow approaches of CaMeL (arXiv 2503.18813) and FIDES (arXiv 2505.23643). [BAL-6.22](../../controls/control-catalog.md#bal-6-22) ([T3](../../guides/tiering.md#t3)) requires provenance-tracked execution of this kind for agents that have any action class at [A4](../../guides/tiering.md#a4) and process untrusted content. It is recommended for other Critical assets.

## Implementation notes

Informative guidance: examples, standards and parameter defaults. The requirement text above is what an assessor tests.

| ID | Control | Notes |
|---|---|---|
| [BAL-6.1](../../controls/control-catalog.md#bal-6-1) | Authority set outside the model | Build the tool set per session from the agent's registration and user entitlements. Taint the session when an item with an untrusted origin label ([BAL-6.2](../../controls/control-catalog.md#bal-6-2)) enters context. Take recipients from fields resolved by code, such as the sender being answered, never from content. ShareLeak (CVE-2026-21520), where injected form text made an agent email data out, is the pattern this breaks. [BAL-3.5](../../controls/control-catalog.md#bal-3-5) decides if the combination is allowed; this control gates each action. |
| [BAL-6.2](../../controls/control-catalog.md#bal-6-2) | Untrusted content labeling and normalization | Code points to handle: U+E0000-E007F (tags), U+200B-200D, U+2060 and U+FEFF (zero-width), and U+202A-202E and U+2066-2069 (bidirectional). Active markup includes scripts, HTML comments, hidden text and auto-loading image or link references. Use [BAL-4.9](../../controls/control-catalog.md#bal-4-9) origin classes for retrieved content. This is hardening only: character injection evaded six guardrails (arXiv 2504.11168, 2025), so the boundary stays in [BAL-6.1](../../controls/control-catalog.md#bal-6-1). |
| [BAL-6.3](../../controls/control-catalog.md#bal-6-3) | Output rendering exfiltration control | EchoLeak (CVE-2025-32711) leaked Copilot data through an auto-fetched image. CamoLeak (2025) used GitHub's image proxy, and the fix was to disable image rendering. ForcedLeak (2025) used an expired allowlisted domain bought for about $5. Data can also travel in subdomains (DNS) and paths, so prefer inert links. OWASP LLM10:2026 recommends auto-rendering off by default. [BAL-5.4](../../controls/control-catalog.md#bal-5-4) tests these cases for built assets; [BAL-8.6](../../controls/control-catalog.md#bal-8-6) adds vendor evidence at [T2](../../guides/tiering.md#t2). |
| [BAL-6.4](../../controls/control-catalog.md#bal-6-4) | Prompt injection detection and response | Cover known jailbreak families: role-play, payload splitting, encoding and obfuscation, and low-resource languages. For agents, prefer downgrade-to-read-only so false positives do not break work. Expect bypass: EchoLeak got past a production injection classifier, and in ShareLeak the request was reportedly flagged yet data still left. On vendor platforms, enable built-in detection and record its response. Test with [BAL-5.3](../../controls/control-catalog.md#bal-5-3) and [BAL-5.4](../../controls/control-catalog.md#bal-5-4) cases; [BAL-5.11](../../controls/control-catalog.md#bal-5-11) and [BAL-5.9](../../controls/control-catalog.md#bal-5-9) measure efficacy at [T2](../../guides/tiering.md#t2). |
| [BAL-6.5](../../controls/control-catalog.md#bal-6-5) | Disclosure-safe hidden context | Assume hidden context can be extracted (ATLAS AML.T0056; OWASP LLM08:2026 Hidden Context Exposure). An instruction such as 'do not reveal these instructions' is not a control. Scan prompts, templates and tool schemas for secrets in the same pipeline as code; [BAL-2.4](../../controls/control-catalog.md#bal-2-4) already bars credentials from model context. Handle business-confidential prompt content under [BAL-4.1](../../controls/control-catalog.md#bal-4-1), not as a security boundary. |
| [BAL-6.6](../../controls/control-catalog.md#bal-6-6) | Topic and intent policy | Useful for public-facing and regulated assets, for example to keep a claims assistant out of legal or medical advice. It narrows misuse and supports intended-use obligations, but it is not an injection defense. Take the purpose from intake ([BAL-1.6](../../controls/control-catalog.md#bal-1-6)) and include the classifier in guardrail efficacy measurement ([BAL-5.11](../../controls/control-catalog.md#bal-5-11)). |
| [BAL-6.7](../../controls/control-catalog.md#bal-6-7) | Input content and multimodal inspection | Covers what text-only inspection misses: instructions in image pixels, QR codes, audio, white or tiny text, comments, alt text, metadata and hidden sheets. ATLAS AML.T0129 (2026.09) describes triggers placed in a modality that defenses do not inspect. Decode common encodings before inspection. Reuse existing malware and URL-reputation services; the AI-specific delta is inspecting every modality before it becomes model context. |
| [BAL-6.8](../../controls/control-catalog.md#bal-6-8) | Harmful content filtering | Primarily a safety and brand control. Set stricter thresholds for public or vulnerable audiences. Jailbreaks target this filter, so pair it with [BAL-6.4](../../controls/control-catalog.md#bal-6-4) and include it in guardrail efficacy measurement ([BAL-5.11](../../controls/control-catalog.md#bal-5-11)). |
| [BAL-6.9](../../controls/control-catalog.md#bal-6-9) | Groundedness checks for decision support | A reliability and misinformation control (OWASP LLM07:2026). A poisoned source still yields a well-grounded answer, so this does not replace source trust labeling ([BAL-4.9](../../controls/control-catalog.md#bal-4-9)), content labeling ([BAL-6.2](../../controls/control-catalog.md#bal-6-2)) or retrieval-generated citations ([BAL-4.12](../../controls/control-catalog.md#bal-4-12)). Decision support includes eligibility, pricing, claims, HR and security triage. Set the threshold from validation on the asset's own test set. |
| [BAL-6.10](../../controls/control-catalog.md#bal-6-10) | Safe handling of model output by interpreters | The AI form of downstream injection (OWASP LLM10:2026, ASI05). Examples: text-to-SQL through read-only roles or parameterized views with row limits; no eval or shell=True on model output; context encoding to prevent script injection in agent-built pages. Vendor coding agents typically meet this through [BAL-6.13](../../controls/control-catalog.md#bal-6-13) sandboxing. Commit-time scanning of generated code is [BAL-5.22](../../controls/control-catalog.md#bal-5-22). |
| [BAL-6.11](../../controls/control-catalog.md#bal-6-11) | Structured output validation | Covers extracted fields, classifications and decisions that feed workflows, APIs or other agents. A provider's structured-output mode reduces malformed output but does not replace validation by the consumer. Validation limits how far a manipulated or faulty response can travel (ASI08). |
| [BAL-6.12](../../controls/control-catalog.md#bal-6-12) | Agent execution limits | Suggested starting defaults, tuned per workflow: 50 tool calls and 30 minutes for interactive tasks, recursion depth 3, five sub-agents, and three identical calls without new results. Limits come from the agent's registration, not its prompt. Automatic halting across tasks is [BAL-3.11](../../controls/control-catalog.md#bal-3-11) and per-agent budgets are [BAL-3.10](../../controls/control-catalog.md#bal-3-10) (both [T2](../../guides/tiering.md#t2)); provider spend ceilings are [BAL-3.8](../../controls/control-catalog.md#bal-3-8). ATLAS AML.M0036 covers similar resource bounds. |
| [BAL-6.13](../../controls/control-catalog.md#bal-6-13) | Agent execution isolation | The Claude Code GitHub Action's file-read tool sat outside its shell sandbox, and injected instructions read /proc/self/environ to expose an API key (Microsoft, June 2026). METR (August 2026) traced evaluation agents reaching Hugging Face through a package proxy and an internet-connected sandbox. Build each run from a clean image (ATLAS AML.M0032), broker credentials where possible ([BAL-2.11](../../controls/control-catalog.md#bal-2-11), [T2](../../guides/tiering.md#t2)) and test for escapes. Ambient credentials are those the task does not need (developer and machine credentials); the agent's own task credentials are governed by [BAL-2.4](../../controls/control-catalog.md#bal-2-4), and brokering them outside the agent's reach is the [T2](../../guides/tiering.md#t2) control [BAL-2.11](../../controls/control-catalog.md#bal-2-11). |
| [BAL-6.14](../../controls/control-catalog.md#bal-6-14) | Agent egress control | In CVE-2025-55284, auto-approved ping and nslookup let a coding agent exfiltrate .env contents through DNS. ForcedLeak shows why listed domains need expiry monitoring. Suggested cadence: quarterly review, with daily expiry and ownership checks. Exfiltration through rendering in the user's client is [BAL-6.3](../../controls/control-catalog.md#bal-6-3). Restricting allowed multi-tenant services to the organization's own accounts is [BAL-6.15](../../controls/control-catalog.md#bal-6-15) ([T2](../../guides/tiering.md#t2)). |
| [BAL-6.15](../../controls/control-catalog.md#bal-6-15) | Tenant-restricted egress | In the Claude Cowork case reported by PromptArmor, the sandbox blocked most domains but allowed the model provider's API, and an injected command uploaded files using the attacker's API key. Mechanisms include tenant-restriction headers at the proxy, credential injection that replaces any caller-supplied key, and rules scoped by account or path for code hosts and storage. |
| [BAL-6.16](../../controls/control-catalog.md#bal-6-16) | Agent and coding-tool configuration lockdown | In CVE-2025-53773, an injected coding agent switched on auto-approve in workspace settings. In CVE-2026-35603, a managed-settings file in a user-writable location let low-privileged users plant configuration. s1ngularity (2025) malware invoked AI CLIs with bypass flags. Repository-supplied configuration includes hooks, MCP definitions, agent settings and dev-container files. Prefer stdio for local MCP servers. Suggested remediation period: 5 business days. Endpoint discovery of these tools is [BAL-1.9](../../controls/control-catalog.md#bal-1-9). Vendor classifier-based or 'auto' modes that execute actions without per-action approval count as auto-approve modes: disabled on managed endpoints, or used only in approved disposable sandboxes after a promotion gate ([BAL-3.1](../../controls/control-catalog.md#bal-3-1)). |
| [BAL-6.17](../../controls/control-catalog.md#bal-6-17) | AI platform and SaaS tenant configuration baseline | Incidents came from tenant defaults. ServiceNow Now Assist agents were discoverable and grouped into one team by default (AppOmni, 2025), and Agentforce enforced Trusted URLs only after ForcedLeak. Start from vendor baselines, with agent discovery, cross-agent delegation and public sharing off unless approved. Role separation follows [BAL-1.2](../../controls/control-catalog.md#bal-1-2). Suggested: assess monthly and after vendor feature notices ([BAL-8.8](../../controls/control-catalog.md#bal-8-8)); remediate within 30 days, or 72 hours for settings that expose data publicly. |
| [BAL-6.18](../../controls/control-catalog.md#bal-6-18) | Non-bypassable AI policy enforcement point | Prevents a new code path or developer shortcut from skipping [BAL-3.2](../../controls/control-catalog.md#bal-3-2) and [BAL-6.4](../../controls/control-catalog.md#bal-6-4) checks. Issue provider keys only to the enforcement point so direct calls fail, and reconcile provider usage against its logs. A model fallback uses an alternative enforcement path that continues to satisfy all mandatory controls; otherwise model traffic fails closed. Tool and MCP traffic always fails closed when required enforcement is unavailable. When self-hosted, the enforcement point is a critical asset under [BAL-6.19](../../controls/control-catalog.md#bal-6-19). |
| [BAL-6.19](../../controls/control-catalog.md#bal-6-19) | Self-hosted AI service exposure and hardening | Langflow CVE-2026-33017, an unauthenticated RCE, was exploited within about 20 hours of disclosure and added to CISA KEV. Researchers counted about 175,000 publicly exposed Ollama hosts in January 2026. Model endpoints are inventoried under [BAL-1.8](../../controls/control-catalog.md#bal-1-8) and components of built assets under [BAL-1.7](../../controls/control-catalog.md#bal-1-7); this control adds exposure for every self-hosted AI service. Suggested KEV timeline: the CISA KEV due date. Treat gateways as tier-0 because every guardrail depends on them. |
| [BAL-6.20](../../controls/control-catalog.md#bal-6-20) | Agentic browser containment | Agentic browsers act inside the user's sessions while reading arbitrary pages. In CometJacking (LayerX, 2025), one crafted URL led to exfiltration of mail and calendar data. CSO Online reported in December 2025 that Gartner analysts advised blocking AI browsers. Enforce this through browser and application management, and find unapproved AI browsers through endpoint discovery ([BAL-1.9](../../controls/control-catalog.md#bal-1-9)). Desktop computer-use agents are covered by [BAL-6.13](../../controls/control-catalog.md#bal-6-13). |
| [BAL-6.21](../../controls/control-catalog.md#bal-6-21) | Agent-to-agent authentication and authorization | AppOmni (November 2025) showed second-order injection between ServiceNow agents that were discoverable by default. Signed Agent Cards in [A2A v1.0.1](https://a2a-protocol.org/v1.0.1/specification/) provide discovery-metadata authenticity and integrity; the protocol's separate request-authentication requirements still apply. Authentication does not stop injected content from propagating, so the receiving agent's own controls ([BAL-6.1](../../controls/control-catalog.md#bal-6-1), [BAL-3.5](../../controls/control-catalog.md#bal-3-5)) still apply. For all assets, the [BAL-6.17](../../controls/control-catalog.md#bal-6-17) baseline also covers agent discovery settings. |
| [BAL-6.22](../../controls/control-catalog.md#bal-6-22) | Provenance-tracked execution | Two patterns. In CaMeL (arXiv 2503.18813), a privileged planner sees only the trusted request, a quarantined model handles untrusted data, and an interpreter enforces policy at each tool call. FIDES (arXiv 2505.23643) applies confidentiality and integrity labels to messages and tool results. Expect a utility cost: CaMeL completed 77% of AgentDojo tasks against 84% undefended. Guarantees do not automatically compose across agent hierarchies. |

## Evidence examples

Examples of evidence an assessor can request. They are illustrative; any evidence that demonstrates the outcome is acceptable.

| ID | Control | Evidence examples |
|---|---|---|
| [BAL-6.1](../../controls/control-catalog.md#bal-6-1) | Authority set outside the model | Configuration showing per-session tool and scope assembly from the authenticated principal; test results where injected content tries to add a tool, widen a scope or change a recipient and fails; policy decision logs for egress actions after untrusted content entered a session. |
| [BAL-6.2](../../controls/control-catalog.md#bal-6-2) | Untrusted content labeling and normalization | Context-assembly code or configuration showing origin labels and size limits; test results for inputs carrying tag, zero-width and bidirectional characters and hidden markup; configuration showing tool output and fetched content cannot populate the system prompt or agent configuration. |
| [BAL-6.3](../../controls/control-catalog.md#bal-6-3) | Output rendering exfiltration control | Renderer or tenant configuration showing remote-content fetching and unfurls disabled or limited to listed origins; quarterly allowlist review record with removed entries; test results showing canary data in Markdown, reference-style and invisible-Unicode link variants is not fetched. |
| [BAL-6.4](../../controls/control-catalog.md#bal-6-4) | Prompt injection detection and response | Detector configuration covering user input and each untrusted input path in the threat model; the documented response for the asset; sample security events in the monitoring platform showing the response taken. |
| [BAL-6.5](../../controls/control-catalog.md#bal-6-5) | Disclosure-safe hidden context | Secret-scan results for system prompts, templates and tool schemas; review record mapping each restriction in hidden context to the control that enforces it outside the model; extraction test showing disclosed context yields no credentials or bypass. |
| [BAL-6.6](../../controls/control-catalog.md#bal-6-6) | Topic and intent policy | Topic and intent policy for the asset derived from its registered purpose; classifier or routing configuration; test results or sampled logs showing restricted requests refused or routed. |
| [BAL-6.7](../../controls/control-catalog.md#bal-6-7) | Input content and multimodal inspection | Inspection pipeline configuration listing each accepted modality; test results for instructions hidden in an image, an audio clip and a document's hidden text; logs of detections handled under the [BAL-6.4](../../controls/control-catalog.md#bal-6-4) response. |
| [BAL-6.8](../../controls/control-catalog.md#bal-6-8) | Harmful content filtering | Harm-category policy with thresholds for the asset; output filter configuration on the response path; test results or sampled logs showing blocked, modified and escalated outputs with reviewer decisions. |
| [BAL-6.9](../../controls/control-catalog.md#bal-6-9) | Groundedness checks for decision support | Groundedness scoring configuration and threshold for each decision-support use; validation results supporting the chosen threshold; sampled responses showing recorded scores and the flag shown to users. |
| [BAL-6.10](../../controls/control-catalog.md#bal-6-10) | Safe handling of model output by interpreters | Design or code review record of parameterization, encoding or sandboxing at each point where model output reaches an interpreter; test results with injected SQL, shell and script payloads in model output; database role or sandbox configuration used. |
| [BAL-6.11](../../controls/control-catalog.md#bal-6-11) | Structured output validation | Schema for each structured output consumed downstream; validator configuration at the consuming boundary; test results or logs showing malformed or out-of-range outputs rejected and routed for handling. |
| [BAL-6.12](../../controls/control-catalog.md#bal-6-12) | Agent execution limits | Runtime or platform configuration showing limits for each agent; test showing a looping or over-long task is terminated; log entries for terminated tasks naming the limit exceeded. |
| [BAL-6.13](../../controls/control-catalog.md#bal-6-13) | Agent execution isolation | Sandbox or VM configuration per agent showing filesystem, credential and network boundaries; test results in which the agent tries to read credential files, instance metadata and its own configuration and is denied; credential inventory showing coding agents hold no production or publishing tokens. |
| [BAL-6.14](../../controls/control-catalog.md#bal-6-14) | Agent egress control | Egress proxy or firewall policy for agent runtimes showing default deny and the allowlist; test results showing direct DNS and unlisted destinations blocked from inside the sandbox; allowlist review and domain-expiry monitoring records. |
| [BAL-6.15](../../controls/control-catalog.md#bal-6-15) | Tenant-restricted egress | List of allowed multi-tenant destinations with the restriction mechanism for each; proxy or gateway rules enforcing tenant or account restriction; test showing a request carrying a foreign API key or tenant is blocked. |
| [BAL-6.16](../../controls/control-catalog.md#bal-6-16) | Agent and coding-tool configuration lockdown | Managed settings deployed to endpoints with bypass and auto-approve disabled and file ownership verified; workspace-trust test using a repository with a malicious hook; baseline-drift and exposed-interface reports with remediation records. |
| [BAL-6.17](../../controls/control-catalog.md#bal-6-17) | AI platform and SaaS tenant configuration baseline | Approved baseline for each AI platform and SaaS tenant per user group; configuration assessment comparing live settings with the baseline; remediation records for deviations closed within the defined period. |
| [BAL-6.18](../../controls/control-catalog.md#bal-6-18) | Non-bypassable AI policy enforcement point | Routing and credential restrictions showing that application code cannot bypass the enforcement point; direct-bypass and outage tests proving tool/MCP denial and preservation of mandatory model controls; provider-usage reconciliation with investigated bypass attempts. |
| [BAL-6.19](../../controls/control-catalog.md#bal-6-19) | Self-hosted AI service exposure and hardening | Inventory of self-hosted AI services with owner and exposure status; external attack-surface scan showing no unapproved internet-reachable AI service; vulnerability records showing KEV-listed AI framework fixes within the timeline. |
| [BAL-6.20](../../controls/control-catalog.md#bal-6-20) | Agentic browser containment | Browser and application management policy blocking AI browsers and agent modes; approval record for any permitted product showing profile isolation or site limits and confirmation settings; sample agent action logs. |
| [BAL-6.21](../../controls/control-catalog.md#bal-6-21) | Agent-to-agent authentication and authorization | Register of permitted agent-to-agent paths with discovery settings; caller-credential and peer-identity verification configuration; negative tests showing that a copied valid descriptor does not authorize a request with invalid credentials, and that an unlisted call is refused; a test showing halt propagation down the chain. |
| [BAL-6.22](../../controls/control-catalog.md#bal-6-22) | Provenance-tracked execution | Design record of the provenance-tracking mechanism and its sink policies; test results where untrusted values are blocked at each sensitive sink; policy decision logs showing provenance labels on evaluated values. |
